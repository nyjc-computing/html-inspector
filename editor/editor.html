    What does the Doctor check?
    
  
    
    
    Browsers hide HTML mistakes to keep pages looking fine — which is friendly, but confusing
       when your page does something you didn't expect. The Doctor re-reads your code the strict
       way and marks everything the browser silently forgives, decides, or moves around.
    
    
    
      error — the code is invalid; browsers guess what you meant.
        warning — legal-looking but the browser will reshuffle it.
        hint — allowed, but worth knowing.
    
    
    
    HTML checks
    
    
    
      
    CheckExample
    
      
    Missing doctype<!doctype html> must be the very first line — without it the browser renders in "quirks mode"
    
      
    Singleton elements used twicea second <body>, <head>, <html> or <title>
    
      
    Tags that intersect (crossed nesting)<b><i></b></i> — close inner tags first
    
      
    Wrong parent (hierarchy)<td> directly inside <table> without a <tr>
    
      
    Invalid tag<imag>, <seciton> — browsers show them as plain text
    
      
    Invalid attribute for the element<img scr="…">
    
      
    Invalid attribute valuealign="centre", colspan="x"
    
      
    Missing closing taga <div> never closed
    
      
    Closing tag on a void element</br> — <br> has no content
    
      
    Stray closing tag</div> with nothing open
    
      
    Unclosed quote in an attributealt="my photo — swallows the rest of the line
    
      
    Content in the wrong placevisible content inside <head> (browsers move it), <style> in <body>
    
      
    Block element inside a paragraph<p><div>…</div></p> — the paragraph splits in two
    
      
    Unterminated <title>/<style>/<script>everything after it disappears from the page
    
      
    Stray &write &amp;
    
    
    
    
    Tips
    
    
      
      
    • Tab indents. Esc collapses this details pane — the ▲ button at the bottom-right brings it back.
      • 
      
    • The preview re-renders automatically shortly after you stop typing — a small amber note tells you when it is momentarily out of date.
      • 
      
    • The page opens pre-filled with a buggy example on purpose: move the cursor onto the underlines to diagnose it. Correct examples: ?example=starter and ?example=table in the address.
      • 
      
    • Only the HTML is checked for now — CSS checking arrives in a separate lesson.
      • 
      
    • Only HTML 4 elements are in scope (that's the course syllabus). HTML5-only tags such as
          <header> get a warning, not an error.
      • 
      
    • Elements whose closing tag HTML 4 lets you omit (<li>, <p>,
          <td>…) are never flagged — but adding the closing tag makes the structure easier to see.
      • 
      
    • Your code is saved in this browser automatically.
